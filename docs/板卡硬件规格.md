# RDK X5 开发板硬件规格与实测性能

> 实测日期:2026-08-15 | 采集:雪猫(板载实测,非官方数据)
> 标注:[实测]=本机采集 [标称]=官方规格(以 D-Robotics 文档为准)

## 一、核心规格速览(给 Agent/LLM 的压缩版)
```
板卡: D-Robotics RDK X5 V1.0(SoC: 地平线征程6E J6E)
CPU: 8× Cortex-A55,300MHz~1.5GHz [实测],NEON/FP16/ASIMD-DP 指令集
内存: 8GB [标称],实测可用 6.9GiB
存储: eMMC 59.5GB [实测],当前剩余约 40GB
AI 算力: BPU 10 TOPS [标称],系统可见 bpu 设备,ION 预留 320MB
GPU: /dev/dri card0 + renderD128 可用 [实测]
相机: MIPI CSI ×2 [标称,当前未接];USB 相机支持(hobot_usb_cam)
网络: 千兆以太网 [实测 1000Mb/s] + WiFi 模块 + CAN 总线(can0) [实测]
外设: 8× UART(ttyS0~S7)、多路 I2C、GPIO(40pin)、USB3.1 Hub [实测]
系统: Ubuntu 22.04.5 LTS(aarch64),内核 6.1.83(hobot 定制),ROS2 Humble + TogetheROS.Bot
```

## 四、给 Agent 工具的关键提示
1. **能跑什么**:8 核 A55 适合 SLAM(nav2+cartographer)、ROS2、轻量 CV(YOLO 小模型走 BPU)、1.5B~3B 量化 LLM;不适合大模型训练/重型渲染
2. **BPU 用起来**:地平线 dnn_node 把模型部署到 BPU(10 TOPS),CPU 基本不占——CV 推理建议走 BPU 而非 CPU
3. **接口富余**:8 路 UART + CAN + I2C + GPIO,接单片机/传感器绰绰有余;串口免 sudo(dialout 组)
4. **电源/功耗**:未实测,以官方手册为准(建议 5V/4A 级供电)
5. **相机注意**:MIPI CSI 目前已接入;USB 相机即插即用(hobot_usb_cam)
