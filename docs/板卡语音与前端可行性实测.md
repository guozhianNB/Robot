## 1. 板上实跑数据（sherpa-onnx CPU）

测试脚本：`.tmp/board_voice_bench.py`（上板到 `/tmp/board_voice_bench.py`）

| 模块 | 模型加载 | 推理吞吐 | 结论 |
|---|---|---|---|
| VAD (silero) | 0.15s | 20s 音频扫完 1.017s = **20× 实时** | ✅ 轻松 |
| ASR (streaming-zipformer-zh-14M) | 7.27s | 4.0s 音频解码 1.02s = **3.9× 实时**（RTF 0.254） | ✅ 实时余量够 |
| TTS (vits-zh-ll, 115MB) | 8.64s | 1.93s 音频耗时 15.07s → **RTF 7.79**；2.49s 音频 12.93s → **RTF 5.19** | ❌ 远低于实时 |

TTS 线程数扫描（同句 1.88s 音频）：

| num_threads | 耗时 | RTF | 倍数 |
|---|---|---|---|
| 2（代码现状） | 13.24s | 7.06 | 0.14× |
| 4 | 6.88s | 3.67 | 0.27× |
| 8 | 4.23s | 2.26 | 0.44× |

→ 即使吃满 8 核，**说 1 秒的话仍要 ~2.3 秒才合成得出来**；板卡上还能"跑"，但对话一轮多句时会持续欠账（且 8 核被 TTS 占满会挤 ROS2/导航）。

## 2. 关于 "nvidia-xxx 环境"

- **项目代码零 CUDA 依赖**：全仓 `*.py` 中 `nvidia|cuda|device_map` 无命中；唯一命中在 `docs/1.pre/教程_PyTorch基础.md`（学习教程，非运行链路）。
- **声纹链路显式指定 CPU**：`LLM/voice/speaker.py:67` `pipeline(task="speaker-verification", model=..., device="cpu")`。
- **modelscope 对无 CUDA 环境自动回退**：`modelscope/utils/device.py::create_device()` 里 `if not torch.cuda.is_available(): logger.info('cuda is not available, using cpu instead.')`；模型侧 `ERes2NetV2.py:340` 加载 ckpt 时 `map_location=torch.device('cpu')`。
- **aarch64 上 pip 不会拉 nvidia-* 包**：PyPI 的 `manylinux_2_28_aarch64` torch 是 CPU 构建（与 x86_64 的 ~900MB CUDA/捆绑轮子不同）。所以"依赖里出现 nvidia-xxx"如果指的是 torch 生态，在本板卡上不会发生。
- 板卡的加速器是**地平线 BPU**（不是 NVIDIA）：`LLM/voice/backend.py` 已预留 `detect_backend()` / `BPU_SUPPORTED`，探测 `hobot_dnn` 决定 bpu/cpu，探测不到就静默回落 CPU。截至本次，`BPU_SUPPORTED` 里只有占位符号 `speaker_eres2netv2`，**BPU runner 尚未实现**。

## 3. 逐项结论

| 能力 | 能否在板卡跑 | 依据 / 缺口 |
|---|---|---|
| **前端（admin/kiosk/nurse）** | ✅ 能 | 纯静态产物（kiosk dist 仅 ~90KB），由 Python 后端 `StaticFiles` 挂载；板卡不需要 Node（板卡没装 Node，也不需要）。缺：把 PC 上构建好的 dist 同步到板卡 |
| **ASR（本地）** | ✅ 能，且有余量 | 3.9× 实时（2 线程）；模型已在板卡 |
| **VAD / KWS** | ✅ 能 | VAD 20× 实时；KWS 模型更小（3.3M），无压力 |
| **TTS（本地 vits-zh-ll）** | ⚠️ 能跑但不能用 | RTF 2.3~7.8，单句合成就比说话还慢；项目默认 `tts_provider=cloud` 是对的 |
| **声纹（ERes2NetV2）** | ⚠️ 需补依赖后测 | 模型已在板、纯 CPU CNN + `torchaudio.Kaldi.fbank` 特征，无 GPU 需求；但板上没 torch/modelscope，**延迟未实测**。推荐按设计文档走 **ONNX 导出 + onnxruntime**（免 torch，省 ~1GB 内存），或后续上 BPU |
| **录音/放音（sounddevice）** | ⚠️ 需补库 | `libportaudio2` 未装（要 sudo apt）；声卡 ES8326 收放都在，`sunrise` 在 audio 组 |

## 4. 待办（需要用户决定/授权）

1. `sudo apt install libportaudio2`（板卡，需明确批准）。
2. `pip3 install --upgrade pip` 后装 sherpa-onnx（已装）、modelscope、torch+torchaudio（~1GB，板卡网速约 250KB/s，预计 1 小时级）。
3. 声纹两种路线二选一：**(a)** torch CPU 直跑 modelscope pipeline（最省事，内存约 1GB+）；**(b)** 按 `2026-08-22-voice-pipeline-design.md` §9 导出 ERes2NetV2 ONNX + onnxruntime（轻、推荐，还能顺带上 BPU）。
4. TTS 策略：保留 `tts_provider=cloud`（默认），板卡本地 TTS 仅作断网兜底；若必须本地，考虑预合成固定话术缓存。
5. 前端：把 PC 构建的 `frontend/packages/*/dist` scp 到板卡，由后端同端口挂载即可。
