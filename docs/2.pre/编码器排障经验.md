## 一、症状链与最终根因（按发现顺序）

| # | 现象 | 排查结论 | 根因 |
|---|---|---|---|
| 1 | 电池不稳，MCU 反复复位、标定跑不完 | 硬件供电 | 电池接触不良（先决条件） |
| 2 | 电机硬启动/短接制动 → 电源过载断电 | 软件冲击 | 无 PWM 斜坡 + 短接制动反电动势回灌 |
| 3 | 4 个编码器全无信号 | 引脚配置 | `GPIO_NOPULL`，开漏编码器读不到高电平 |
| 4 | 手动拉 PB3 无反应 | 正常现象 | TI1 模式 B 相只判方向不计数 |
| 5 | cnt 不动但电平翻转 | **程序读法 bug** | 只读 `md_get_encoder_count` 缓存，没调 `md_get_encoder_delta` 同步硬件 |
| 6 | rpm 乱跳（-380~1200） | OLED 阻塞 | 整帧 OLED 刷新 97ms 打碎 10ms 控制周期 |
| 7 | 电机一颤一颤（开环也颤） | **PWM 频率** | TIM1 Period=65535 → PWM 仅 15Hz，电机只发抖不转 |
| 8 | 速度升不上去 | PID 增益 | Kp 太小，误差大但 PWM 爬升慢 |
| 9 | rpm 数值"怪"（蜗牛爬但 rpm 高） | **单位理解** | rpm 是**电机轴**转速，非轮子转速（有减速比） |

## 二、核心结论（改底盘驱动必看）

### 1. PWM 频率必须是 ~1kHz（第一优先级！）
- TIM1：Prescaler=71（72 分频）、**Period=1000** → 72MHz/72/1001 ≈ 1kHz
- **Period=65535 → 15Hz** → 电机只发抖不转（症状 7，最隐蔽）
- 同步 `.ioc`：`TIM1.Period=1000`（CubeMX 默认是 65535，重新生成会覆盖！）

### 2. 编码器引脚必须上拉
- 开漏编码器（OC）只能拉低，`GPIO_PULLUP` 必须
- `.ioc` 同步 `GPIO_PuPd=GPIO_PULLUP`（8 个编码器引脚）

### 3. TI1 编码器模式：只有 A 相（CH1）计数
- A 相接 CH1：way1→PA15、way2→PA6、way3→PD12、way4→PA0
- A 相接错 → 计数恒 0；B 相只判方向

### 4. 读编码器必须调 `md_get_encoder_delta()`
- `md_get_encoder_count()` 返回驱动层缓存，**只有 delta() 才从硬件同步**
- 自检代码只调 count() 永远显示 0（症状 5）

### 5. 软启动/软停（PWM 斜坡），禁硬启/短接制动
- 启动：PWM 每 20ms 步进 100
- 停止：只降 PWM 不改方向（滑行），禁 `md_set_motor(way,0)` 短接
- 否则反电动势回灌 → 电池过热 → MCU 复位（症状 2）

### 6. 闭环循环内禁止整帧 OLED 刷新
- 100kHz 下整帧刷新 ≈97ms 阻塞 → 打碎 10ms PID 周期 → rpm 乱跳
- 用单页刷新 `OLED_ShowPage()`（~3ms）或提高 I2C 到 400kHz
- 字体用 afont8x6（8px=一页，单页刷新干净）

### 7. PID 参数（最终整定，已写入 control 固件）
- **Kp=6.5 / Ki=2.0 / Kd=0**（实测定稿，`motor_control.c` 默认值与单轮测试一致）
- Kp 太小 → 速度升不上去（起步推力 = Kp×err）
- **积分限幅必须 ≥ 输出限幅（1000）**：原 150/600 会把 PID 输出封顶
  （实测 150→pwm 卡 42，600→pwm 卡 214，速度永远上不去）
- 防饱和靠"条件积分（输出饱和时冻结）+ 输出限幅 ±1000"双保险，积分限幅等效不限幅
- 起步参考：Kp≈2~7 快速响应，Ki≈1~2 快速消除稳态误差，Kd=0（低速量化噪声大）

### 8. TIM5 预分频必须为 0
- 原工程 `htim5.Init.Prescaler = 2-1`（=1）→ 编码器计数减半 → RPM 减半 → PID 输出加倍

## 三、rpm 计算原理（移植前必读！）

### 3.1 当前代码的换算（motor_control.c）

```c
RPM = delta × 60 / (MC_ENCODER_CPR × dt)
```
- `delta`：dt 时间内的编码器脉冲数（带符号）
- `MC_ENCODER_CPR = 28202`：**轮子每圈脉冲数**（实测标定，见 3.4）
- `dt`：采样周期（秒），10ms = 0.01s
- ×60：脉冲/秒 → 转/分钟

### 3.2 rpm 语义 = 轮子转速（已统一）

CPR 用"轮子每圈脉冲"实测值后，rpm 直接就是**轮子转速**，
与 `mc_car_set` 的 mm/s→RPM 换算（也是轮子 RPM）完全统一，无需再除以减速比。

### 3.3 线速度换算（轮子 RPM → mm/s）

```
线速度 mm/s = 轮子RPM × π × 轮径 / 60
           = 轮子RPM × π × 80 / 60
例：100 RPM → 419 mm/s；48 RPM → 201 mm/s（≈200mm/s 标准行驶）
```

### 3.4 CPR 实测标定方法（本车已测得 28202）

- 手动把轮子转 N 整圈（记号笔标记），读编码器累计脉冲
- `PPR = 总脉冲 / N`（本车 10 圈 → 28202，两次复核 28219/28202，误差 0.06%）
- ⚠️ 读计数前必须先调 `md_get_encoder_delta()` 同步硬件→缓存（缓存读法坑！）
- ⚠️ 转完停下 2 秒后读数，圈数必须精确（标记点回原位）

### 3.5 完整换算表（轮子参考系，定稿）

```
电机轴每圈脉冲（编码器原始） = PPR / 减速比    （仅需要电机轴语义时才用）
轮子 RPM（PID 反馈/目标）    = delta×60/(28202×dt)
轮子线速度 mm/s             = 轮子RPM × π × 80 / 60
里程（距离 mm）             = 累计脉冲 × π × 80 / 28202
```

### 3.6 里程计落地公式（已定稿）

```
行驶距离 mm = 累计脉冲 × π × 轮径 / PPR
            = 累计脉冲 × π × 80 / 28202
            约 0.0089 mm/脉冲
```
