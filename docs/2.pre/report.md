## 二、按子系统归类

### 2.1 计算与控制核心

| 项目 | 费用 |
|:----|:---:|
| Nano Super 8GB (Jetson Orin Nano Super) | 3,869.00 |
| **小计** | **3869.00** |

> Jetson 承担所有"大脑级"运算（LLM 推理、视觉 AI、传感器融合、语音处理），STM32 负责底盘实时控制（电机 PWM、编码器读取），分工明确。

### 2.2 底盘与运动系统

| 项目 | 费用 |
|:----|:---:|
| 小车底盘 | 31.00 |
| MG513X 电机 ×4 | 315.20 |
| TB6612 电机驱动 | 69.00 |
| 麦轮 + 联轴器 | 53.00 |
| STM32F103ZET6 开发板 | 61.01 |
| **小计** | **529.21** |

> 四轮独立驱动 + 麦轮 → 全向移动，配合激光雷达实现 SLAM 自主导航。

### 2.3 感知与传感器

| 项目 | 费用 |
|:----|:---:|
| T-MINI 激光雷达 | 419.00 |
| LD6002 呼吸心跳雷达 | 74.80 |
| LD6002C 跌倒检测雷达 | 127.00 |
| 红外摄像头 (22pin 160°) | 84.00 |
| IMX219 摄像头 | 47.00 |
| **小计** | **751.80** |

> 激光雷达 → 建图导航；双毫米波雷达 → 夜间的"听诊器 + 哨兵"；双摄像头 → 日夜分时视觉方案。
