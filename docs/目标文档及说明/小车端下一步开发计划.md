## 三、第二步：底盘标定（接上 STM32 后必做，顺序不可乱）

按 `ros2_car/README.md`「底盘接入」节 + `docs/2.pre/编码器排障经验.md`：

1. **轴方向**：pub `linear.x: 0.1` 应直行不偏转；歪了改 `chassis_params.yaml` 的 `sign_vx/sign_wz`；`linear.y`/`angular.z` 同理（麦轮横移正负）
2. **轮径/旋转半径**：直行 1m 对 odom 读数修 `wheel_radius`；原地 360° 修 `rotate_radius`
3. **四轮方向**：个别轮装反用 `wheel_signs` 取反
4. ⚠️ 与固件侧一致：`stm32/control` 的 `MC_WHEEL_DIAMETER_MM`/`MC_ROTATE_RADIUS_MM`
5. 标定完测 `use_ekf:=true`（关底盘 TF、EKF 发 TF，避免双发布）

## 四、第三步：实测第一批契约接口（联调前置）

建图 + 底盘标定通过后，逐个验证（对照 `ROS底盘接口需求.md`）：

```bash
ros2 service call /robot/move robot_interfaces/srv/Move "{direction: forward, distance_m: 0.5}"
ros2 service call /robot/turn robot_interfaces/srv/Turn "{angle_deg: 90}"
ros2 service call /robot/navigate_to robot_interfaces/srv/NavigateTo "{place: '', x: 1.0, y: 0.5, theta: 90}"
ros2 topic echo /robot/exec_state   # idle/moving/navigating/error 应随动作切换
ros2 topic echo /robot/arrived      # 完成 true / 新动作开始 false
```

验收点：**到位自动停**（不冲过头）、急停 `robot/cmd_stop` 能打断动作、状态话题正确切换。
发现参数问题（速度/容差/停滞判定）改 `robot_actions.py` 顶部常量即可。
