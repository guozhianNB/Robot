# 教程
 **这是远程开发教程（其更像是是说明书）**
下面是**注意事项**：

1. 在sunrise用户里面开发，不要用root。root的权限太高了，容易系统自己把自己真实。除非你知道你在干嘛，非必要不用root账户！  
2. 如果开发板什么东西要设密码的话（你自己的账号除外），统一设置为 `sunrise`
3. 非必要不要新建用户   
  



## 一、VNC远程桌面教程
>目的：远程桌面可以让你在电脑上直接看到开发板的桌面环境，方便调试和操作。
### 初次操作：
 - 下载一个TrigerVNC Viewer (附有安装包)
### 启动远程桌面
 - 直接输入`ubuntu.local:5091`,密码同样是`sunrise`

### 启动失败怎么办？手动启动远程桌面教程：
- ssh连接到板卡
- 输入`vncserver -list`,查询显示号
- 输出会类似与：
   ```
   TigerVNC server sessions:
   X DISPLAY #     RFB PORT #      RFB UNIX PATH   PROCESS ID #    SERVER
   1               5901                            1302            Xtigervnc 
   ```
   `X DISPLAY`里面的数字就是显示号
- 你的显示屏幕端口号为： $Port = 5090 + X$
- 这时候再访问`ubuntu.local:端口号`即可
### 还是不行？服务开机未启动？手动启动服务：
- ssh
- 检查服务状态 `systemctl status vncserver@1`
    - 未出现绿色文字“ Active: active (running)”，则服务开机启动失败，使用手动启动
    - 清理已经异常的程序 `vncserver -kill :1 2>/dev/null`
        - 如果报错,则使用强制追杀 `ps aux | grep Xtigervnc | grep -v grep | awk '{print $2}' | xargs kill -9 2>/dev/null`
    - 启动服务端程序 `vncserver :1 -geometry 1920x1080 -depth 24 -localhost no`  
    - ```# 确认进程存在
        ps aux | grep Xtigervnc | grep -v grep
        # 确认端口监听正常
        ss -tlnp | grep 5901
      ```
    - 看到 Xtigervnc 进程且 5901 端口处于 LISTEN 状态，即表示手动启动成功
        - 如果仍未启动成功， 输入`vncserver -list`检查显示号是不是1
        - 如果不是1，从“清理异常程序”开始重新搞一遍
### 小提示  
你会发现远程桌面是无法按下关机键的。想关机请输入指令`sudo poweroff`

## 紧急远程桌面教程
**在VNC彻底失效时紧急使用Windows自带的桌面操控。请注意，该操作会占线，挤掉正常hdmi输出**
**我还未尝试过直接接入yolo全屏时的操控，最好还是不要这么搞**
 - 先ssh连接
 - 先确认注销本地图形界面，在ssh窗口中输入 ` loginctl terminate-user sunrise `
 - 在Windows 端连接，按 Win + R，输入 mstsc，回车
 - 在“计算机”一栏写入 `ubuntu.local`
 - 会弹出蓝色登陆框，登陆
 - 进入Xfce桌面
