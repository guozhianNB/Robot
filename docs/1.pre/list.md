# 硬件清单

> 基于《基于多模态大语言模型与边缘感知的一体化智能养老陪护巡逻系统》项目需求整理

---

## 一、机器人移动平台

- [ ] **ROS/ROS2 机器人底盘**
  - 支持 ROS 导航栈，具备轮式编码器反馈
  - 载重能力满足搭载主控+传感器+电池
  - 可选：TurtleBot4、JetBot、HoloCubic 或自制阿克曼/差速底盘

---

## 二、主控与计算平台

- [ ] **NVIDIA Jetson Orin Nano（推荐）**
  - 作为机器人"本地大脑"，运行视觉AI、语音流水线及传感器融合算法
  - 替代方案：高性能笔记本（需支持 CUDA）
- [ ] **STM32 / ESP32 下位机（可选）**
  - 用于电机驱动、编码器读取等底层控制

---

## 三、传感器组

### 3.1 导航与环境感知

- [ ] **激光雷达 LiDAR**
  - 用于 SLAM 建图与自主导航避障
  - 推荐：RPLIDAR A1/A2、思岚 S series、YDLIDAR
- [ ] **深度相机（可选）**
  - 辅助避障与三维环境感知
  - 推荐：Intel RealSense D435 / OAK-D

### 3.2 视觉与安防监测

- [ ] **RGB 摄像头**
  - 用于白天模式的人脸识别、情感交互
- [ ] **红外夜视摄像头**
  - 用于夜间低照度环境下的人体骨骼关键点检测
  - 推荐：USB 红外夜视模组（如海康威视 USB 摄像头模组）

### 3.3 生命体征监测（进阶）

- [ ] **毫米波雷达**
  - 用于夜间非接触式呼吸/心率监测
  - 推荐：Infineon BGT60LTR11AIP / 怡同科技毫米波雷达模组

---

## 四、语音交互硬件

- [ ] **麦克风阵列**
  - 用于远场语音唤醒与拾音（支持噪声抑制）
  - 推荐：ReSpeaker 4-Mic / 2-Mic Array
- [ ] **扬声器 / 功放模块**
  - 用于 TTS 语音播报与情感交互

---

## 五、电源与续航

- [ ] **锂电池组**
  - 为整机供电，容量满足 4~8 小时续航
- [ ] **自动回充模块**
  - 实现低电量自动返回充电桩
- [ ] **电压检测模块**
  - 实时监测电量状态

---

## 六、辅助与扩展

- [ ] **Wi-Fi / 4G 通信模块**
  - 与云端 API 通信（调用大模型、推送告警）
- [ ] **USB HUB**
  - 扩展多路 USB 设备（摄像头、雷达、麦克风等）
- [ ] **结构件与固定件**
  - 用于固定传感器、主控板到底盘上

---

> **备注：** 打 `- [ ]` 表示待采购/准备，可根据实际分工调整。遵循"模块化开发、逐步集成"策略，先购置基础底盘+主控+核心传感器，后续逐步添加进阶模块。
