# 学习路线图

> 从 Python 新手到完成本项目所需的知识体系，按优先级分阶段学习。

---

## 🟢 第一阶段：Python 基础夯实（预计 2~3 周）

> **目标：** 能独立写脚本、调试代码、使用第三方库。

| 学习内容 | 为什么需要 | 推荐资源 |
|---------|-----------|---------|
| **Python 语法核心**：变量、数据类型、条件、循环、函数、类 | 项目全部用 Python 开发 | 廖雪峰 Python 教程 / 菜鸟教程 |
| **文件读写与路径处理**：`open()`、`os`、`pathlib` | 读取配置文件、保存日志/图片 | |
| **第三方库安装与虚拟环境**：`pip`、`venv` / `conda` | 管理项目依赖，避免环境冲突 | |
| **基础调试能力**：`print()` 调试、`pdb` 断点、读报错信息 | 90% 的时间在调试，必须会 | |
| **NumPy / OpenCV 入门**：数组操作、读取/显示/保存图片 | 视觉模块的基础 | |

**✅ 阶段验收：** 能写一个脚本，读取一张图片，用 OpenCV 转灰度并保存。

---

## 🟡 第二阶段：视觉与AI感知（预计 3~4 周）

> **目标：** 能跑通目标检测模型，理解骨骼关键点识别。

| 学习内容 | 为什么需要 | 推荐资源 |
|---------|-----------|---------|
| **OpenCV 进阶**：颜色空间、ROI 裁剪、视频流 `VideoCapture` | 处理摄像头画面 | 官方教程 + 实验 |
| **YOLOv8 入门**：用 Ultralytics 跑目标检测 | 白天识别人脸/物体 | Ultralytics 官方文档 |
| **YOLOv8-pose 骨骼关键点检测** | 夜间跌倒检测核心算法 | |
| **MediaPipe 基础** | 轻量级姿态估计，可作备选方案 | Google MediaPipe 官方示例 |
| **PyTorch 基础**：张量、模型加载与推理（不求训练） | 加载和运行预训练模型 | PyTorch 官方 60min 教程 |

> 💡 **小提示：** 这一阶段不用自己训练模型，先用别人训练好的权重跑通推理，理解输入/输出是什么。

**✅ 阶段验收：** 能用 YOLOv8-pose 对一段视频实时绘制骨骼关键点。

---

## 🟠 第三阶段：语音交互（预计 2 周）

> **目标：** 跑通"语音 → 文字 → 大模型 → 语音"回路。

| 学习内容 | 为什么需要 |
|---------|-----------|
| **调用 API 基础**：`requests` 库、HTTP POST/GET、JSON 解析 | 调用 DeepSeek/Qwen 大模型 API |
| **百度语音 / 讯飞 ASR 集成**（看官方 SDK 文档） | 语音识别（语音→文字） |
| **百度语音 / 讯飞 TTS 集成** | 语音合成（文字→语音） |
| **Prompt Engineering 基础**：角色设定、Few-shot、System Prompt | 让大模型扮演"专业护工" |
| **音频流处理基础**：`pyaudio` 录音与播放 | 边录边播、控制延迟 |

**✅ 阶段验收：** 对着麦克风说一句话 → 转文字 → 发给 DeepSeek API → 拿到回复 → 语音播报出来。

---

## 🔴 第四阶段：机器人导航基础（预计 3~4 周）

> **目标：** 能用 ROS 让小车动起来、建图、导航。

| 学习内容 | 为什么需要 |
|---------|-----------|
| **ROS 核心概念**：节点(Node)、话题(Topic)、服务(Service) | ROS 是机器人系统的"操作系统" |
| **ROS 常用命令**：`rosrun`、`rostopic`、`rviz` | 调试和查看传感器数据 |
| **URDF 模型文件** | 描述机器人结构 |
| **SLAM 建图**：用 `gmapping` / `cartographer` | 让机器人绘制房间地图 |
| **AMCL 定位 + 路径规划** | 让机器人在已知地图中自主导航 |
| **避障**：代价地图(Costmap) 配置 | 让机器人不撞墙 |

> 💡 **小提示：** 先在 ROS 仿真环境（Gazebo / Rviz）里跑，不急着上真车。

**✅ 阶段验收：** 在仿真环境中，让机器人从 A 点自主导航到 B 点并避开障碍物。

---

## 🔵 第五阶段：系统集成（预计 4~6 周）

> **目标：** 将所有模块拼起来，跑通白天/夜间模式切换。

| 学习内容 | 说明 |
|---------|------|
| **多线程 / 异步编程基础**：`threading`、`asyncio` | 同时跑摄像头、语音、导航（各模块不阻塞） |
| **状态机设计**：白天模式 ↔ 夜间模式切换 | 定义机器人行为逻辑 |
| **地瓜派 RDK X5 部署基础**：刷机、安装系统镜像、开启摄像头 | 把代码跑在边缘设备上 |
| **简单 Web 后端（Flask/FastAPI）** | 后台告警推送接口 |
| **微信小程序 / 企业微信机器人告警** | 异常时通知护工 |

**✅ 阶段验收：** 机器人能在白天和你聊天对话，夜间切换为自动巡逻模式。

---

## 📅 建议的时间安排

| 阶段 | 时间 | 分工建议 |
|------|------|---------|
| 第一阶段 | 第 1~3 周 | **全员同步学习**，打好共同基础 |
| 第二阶段 | 第 4~7 周 | **A 队**主攻视觉 (YOLO) + **B 队**主攻语音 (ASR/TTS) |
| 第三阶段 | 第 8~9 周 | **A 队**继续视觉 + **B 队**搞定语音回路 |
| 第四阶段 | 第 10~13 周 | **全员一起**攻 ROS 导航（这块最难） |
| 第五阶段 | 第 14~19 周 | **全员集成**，白天模式 → 夜间模式 → 联调 |
| 缓冲期 | 第 20~24 周 | 打磨、测试、写文档、申请软著 |

---

## 💡 几个建议

1. **不要追求完美，先跑通再优化** —— 先让机器人能动、能说一句话，再考虑延迟优化。
2. **多读官方文档，少看博客二手信息** —— Ultralytics、ROS Wiki、百度 ASR SDK 都有不错的官方文档。
3. **git 一定要用** —— 队友之间用 GitHub/Gitee 协作，避免代码丢失。
4. **遇到问题先记下来** —— 每个踩过的坑都是后面写论文/专利的素材。
