# 车控 MCP 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 PC 后端中提供七个可降级的车控 MCP 工具，通过 rosbridge 安全驱动板卡，并为区域配置可验证的停靠点。

**架构：** 板卡 `robot_actions` 新增快速 readiness 服务和状态心跳；PC MCP 子进程用 ctrl/stop/state/probe 四条 websocket 隔离长动作、急停、订阅和就绪探测。导航目标只从当前地图的 tags 真相解析，地图或状态不可验证时 fail-closed；异步任务用递增 task_id 防止急停和迟到回调污染状态。

**技术栈：** Python 3、python-mcp、websocket-client、ROS2 Humble/rclpy、rosbridge、pytest、Vue 3、TypeScript、Vite、pnpm。
